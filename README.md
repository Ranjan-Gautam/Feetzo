# Feetzo

Feetzo — official website for a men's fashion & footwear store in Lagankhel, Lalitpur, Nepal. Showcases genuine branded sneakers, shoes, and menswear at fair prices, with sections for Footwear, Outerwear, Pants and Tops.

Feetzo was built on a simple frustration — shops nearby sell cheap, low-quality goods dressed up as bargains. We do it differently: every pair of shoes and every piece of clothing we stock is genuinely branded, carefully checked, and priced fairly. No inflated markups, no compromise on materials — just honest retail the way it should be.

## Collections
- 👟 **Footwear** — Jordan, Nike, Adidas, Timberland, New Balance, Puma and more — sneakers and boots for every day.
- 🧥 **Outerwear** — Leather jackets, down jackets, bombers and coats.
- 👖 **Pants** — Smoker, Black Bird and Cruze: straight, baggy, boot-cut, cargo and denim fits.
- 👕 **Tops** — Tees, hoodies, tracksuits, shirts and knitwear.

Browse the store, then message us on WhatsApp to check availability, sizes and price. Delivery across Nepal. Cash on Delivery, eSewa and Khalti accepted.

## Tech Stack
- [Next.js](https://nextjs.org/) — React framework for routing and performance
- [TypeScript](https://www.typescriptlang.org/) — type-safe development
- [Tailwind CSS](https://tailwindcss.com/) — utility-first styling

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
