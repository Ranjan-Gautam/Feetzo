# Feetzo
Feetzo — official website for a men's fashion &amp; footwear store in Kathmandu. Showcases genuine branded sneakers, shoes, and menswear at fair prices, with sections for Footwear, Men's Clothing, and Best Value Deals.

Feetzo was built on a simple frustration — shops nearby sell cheap, low-quality goods dressed up as bargains. We do it differently: every pair of shoes and every piece of clothing we stock is genuinely branded, carefully checked, and priced fairly. No inflated markups, no compromise on materials — just honest retail the way it should be.

## Collections
- 👟 **Footwear** — Sneakers, formal shoes, and everyday boots from trusted brands, built for Kathmandu's streets and seasons.
- 👔 **Men's Clothing** — Shirts, jackets, and casual wear cut for comfort and style, with fabric quality that holds up.
- 🏷️ **Best Value Deals** — Same branded products sold nearby, at a fairer price.

## Tech Stack
- [Next.js](https://nextjs.org/) — React framework for routing, SSR/SSG, and performance
- [TypeScript](https://www.typescriptlang.org/) — type-safe development
- [Tailwind CSS](https://tailwindcss.com/) — utility-first styling

## Getting Started

First, install dependencies:

\`\`\`bash
npm install
# or
yarn install
\`\`\`

Then run the development server:

\`\`\`bash
npm run dev
# or
yarn dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
